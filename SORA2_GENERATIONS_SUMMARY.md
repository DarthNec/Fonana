## 🎨 UI Компоненты

### Счетчик генераций (CreatePostModal)

```tsx
┌────────────────────────────────────────────┐
│ ✨ Available generations:            3     │
└────────────────────────────────────────────┘
```

**Цвета**:
- `> 0`: Зеленый (`text-green-600`)
- `= 0`: Красный (`text-red-600`)

**Предупреждение при 0**:
```
⚠️ No generations available. You cannot create Sora-2 videos.
```

## 🔄 Workflow

### Успешное создание AI-видео

```
1. Открытие модалки
   → GET /api/user/generations
   → Отображение: "Available generations: 3"

2. Выбор Sora-2
   → Отображение счетчика
   → Кнопка активна

3. Создание поста
   → POST /api/posts (type: 'ai-video')
   → Проверка: availableGenerations > 0 ✅
   → Декремент: 3 → 2
   → Создание поста

4. Обновление UI
   → Локальный счетчик: 3 → 2
   → Toast: "Post created successfully!"
```

### Попытка создания без генераций

```
1. Открытие модалки
   → GET /api/user/generations
   → Отображение: "Available generations: 0"

2. Выбор Sora-2
   → Отображение красного счетчика
   → Предупреждение: "⚠️ No generations available"
   → Кнопка Publish НЕАКТИВНА ❌

3. Невозможность создания
   → Пользователь не может нажать Publish
```

## 🧪 Тестирование

### Проверь следующее:

1. ✅ При открытии модалки загружается счетчик
2. ✅ При выборе Sora-2 счетчик виден
3. ✅ При 0 генерациях кнопка Publish неактивна
4. ✅ При создании AI-видео счетчик уменьшается
5. ✅ При попытке создать без генераций → ошибка 403
6. ✅ После создания локальный счетчик обновляется

### Команды для тестирования

```bash
# Проверить текущий счетчик
curl "http://localhost:3000/api/user/generations?userWallet=YOUR_WALLET"

# Установить счетчик на 0 (для теста)
curl -X POST http://localhost:3000/api/user/generations \
  -H "Content-Type: application/json" \
  -d '{"userWallet":"YOUR_WALLET","generationCount":0}'

# Установить счетчик на 3
curl -X POST http://localhost:3000/api/user/generations \
  -H "Content-Type: application/json" \
  -d '{"userWallet":"YOUR_WALLET","generationCount":3}'
```

## 🔐 Безопасность

### Двойная проверка
1. **Клиент**: Блокировка UI при 0 генерациях
2. **Сервер**: Валидация перед созданием + декремент

### Race Condition Prevention
Декремент выполняется атомарно через Prisma:
```typescript
availableGenerationCount: { decrement: 1 }
```
