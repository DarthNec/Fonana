# Migration: Add isAIanswer field to Message table

**Date**: February 19, 2026

## Purpose

Adds `isAIanswer` boolean field to the `Message` table to track whether a message was generated by AI auto-answer feature.

## Changes

### Schema Changes

**Table**: `Message`

**Added Field**:
- `isAIanswer` (Boolean, NOT NULL, DEFAULT false)

## Migration SQL

```sql
ALTER TABLE "Message" ADD COLUMN "isAIanswer" BOOLEAN NOT NULL DEFAULT false;
```

## How to Apply

```bash
# Apply migration manually
psql -U fonana_user -d fonana -h localhost -p 5432 -f prisma/migrations/20260219_add_is_ai_answer_to_messages/migration.sql

# Or using connection string
psql "postgresql://fonana_user:fonana_pass@localhost:5432/fonana" -f prisma/migrations/20260219_add_is_ai_answer_to_messages/migration.sql

# After applying, regenerate Prisma Client
npx prisma generate
```

## Verification

```sql
-- Check that column was added

-- isAIanswer  | boolean   | false
```

## Rollback

```sql
-- To rollback (if needed)
ALTER TABLE "Message" DROP COLUMN "isAIanswer";
```

## Impact

- ✅ **Safe**: Non-breaking change (adds new field with default value)
- ✅ **Backward compatible**: Existing code will continue to work
- ✅ **No data loss**: All existing messages will have `isAIanswer = false`
- ⚠️ **Action required**: Run `npx prisma generate` after applying migration

## Use Cases

This field will be used to:
1. Distinguish AI-generated messages from human messages
2. Display AI badge/indicator in chat UI
3. Filter/search for AI responses
4. Analytics on AI auto-answer usage
