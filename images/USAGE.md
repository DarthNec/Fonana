# 🎨 Скрипты для работы с изображениями Fonana

## 📦 Установка зависимостей

```bash
cd images
npm install
```

## 🚀 Использование скриптов

### 1. **Тестирование подключения к БД**
```bash
npm run test-db
# или
node update-user-backgrounds.js --test
```

### 2. **Обновление фоновых изображений пользователей**
```bash
npm run update-backgrounds
# или  
node update-user-backgrounds.js
```

### 3. **Загрузка изображений с Unsplash**
```bash
npm run download
# или
node download-images.js
```

## 🔧 Что делает скрипт update-user-backgrounds.js

1. **Подключается к PostgreSQL БД**: `postgresql://fonana_user:fonana_pass@64.20.37.222:5432/fonana`
2. **Находит пользователей** у которых `backgroundImage IS NULL`
3. **Случайно назначает** один из 25 градиентных фонов с Unsplash
4. **Обновляет поле** `backgroundImage` в таблице `users`

## 📊 Доступные фоны (25 штук)

- 🟣 **Фиолетовые градиенты** (3 шт)
- 🔵 **Синие градиенты** (3 шт)  
- 🟢 **Зеленые градиенты** (3 шт)
- 🔴 **Красные и розовые** (3 шт)
- 🟡 **Желтые и оранжевые** (3 шт)
- ⚫ **Темные градиенты** (3 шт)
- 🌈 **Многоцветные** (2 шт)
- 🎨 **Криптостиль** (3 шт)
- ⚪ **Светлые пастельные** (2 шт)

## ⚠️ Важные замечания

- Скрипт обновляет **только** пользователей с `backgroundImage = NULL`
- Уже установленные фоны **НЕ перезаписываются**
- Между обновлениями есть пауза 100мс для снижения нагрузки на БД
- Все URL ведут на оптимизированные изображения 1920x1080px с Unsplash

## 🛠️ Структура базы данных

```sql
-- Поле в таблице users
"backgroundImage" VARCHAR(255) NULL
```

## 📝 Примеры использования

### Проверить сколько пользователей без фона:
```bash
node update-user-backgrounds.js --test
```

### Обновить всех пользователей без фона:
```bash
node update-user-backgrounds.js
```

### Справка по командам:
```bash
node update-user-backgrounds.js --help
```

## 🔍 Логи выполнения

Скрипт выводит подробную информацию:
- Количество найденных пользователей
- Прогресс обновления (N/Total)
- Какой фон назначен каждому пользователю
- Финальную статистику

## 🚨 Обработка ошибок

- **ECONNREFUSED**: Проблемы с подключением к БД
- **28P01**: Неверный логин/пароль
- **3D000**: База данных не найдена
- Ошибки обновления отдельных пользователей не прерывают весь процесс
