# 🚀 DogWater ATA - Быстрый старт

## ✅ Что сделано

Создана система автоматической инициализации токен-аккаунтов (ATA) для DogWater токена.

## 📁 Созданные файлы

1. **`/app/api/dogWater/initwallet/route.ts`** - API endpoint для создания ATA
2. **Интеграция в `/app/api/user/route.ts`** (строки 274-301) - автоматический вызов при выдаче награды

## 🎯 Как это работает

### Автоматический режим (рекомендуется)

Ничего делать не нужно! Система работает автоматически:

1. Пользователь подключает кошелек впервые
2. Система отправляет ему регистрационную награду (2 USD в SOL)
3. **Автоматически создается ATA для DogWater токена**
4. Пользователь готов получать DogWater

### Ручной режим (для тестирования)

```bash
# Создать ATA для конкретного пользователя
curl -X POST http://localhost:3000/api/dogWater/initwallet \
  -H "Content-Type: application/json" \
  -d '{"userWallet":"USER_WALLET_ADDRESS"}'
```

## 🔧 Конфигурация

Система использует те же настройки, что и система наград:

- **RPC**: Helius RPC (уже настроен)
- **Плательщик**: Тот же кошелек, что отправляет награды
- **Токен**: `99smS99MkGP8WFggmUZWaVbe18Y8iWuC3YhGtUMMBray`

## ⚠️ Важно

- ✅ **Идемпотентно** - повторный вызов безопасен
- ✅ **Non-blocking** - ошибка ATA не блокирует выдачу награды
- ✅ **Автоматически** - пользователь ничего не делает
- 💰 Комиссию (~0.002 SOL) платит сервер

## 🧪 Тестирование

1. Подключи новый кошелек к приложению
2. Получи регистрационную награду
3. Проверь в логах создание ATA
4. Проверь в Solscan, что ATA создан
