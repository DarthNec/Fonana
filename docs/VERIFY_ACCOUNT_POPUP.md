# VerifyAccountPopup Component

## 📋 Описание
Компонент верификации аккаунта через покупку DogWater токена на сумму $1 через Jupiter Swap.

## 🎯 Функциональность

### Показ попапа
- Попап показывается автоматически если `user.isBoughtDogWater === false`
- Попап **нельзя** закрыть самостоятельно (модальное окно без кнопки закрытия)
- Скрывается автоматически после успешной верификации

### Процесс верификации
1. **Отображение информации:**
   - Аватар пользователя
   - Username (nickname или fullName)
   - Описание процесса верификации

2. **При нажатии "Верифицировать":**
   - Получает quote от Jupiter API для свапа SOL → DogWater
   - Сумма: 0.001 SOL (~$1)
   - Slippage: 3%
   - Открывается Phantom кошелек для подтверждения

3. **После подтверждения транзакции:**
   - Отправка транзакции в Solana сеть
   - Ожидание подтверждения (commitment: 'confirmed')
   - Вызов API `/api/dogWater` для обновления флага `isBoughtDogWater`
   - Перезагрузка страницы для обновления состояния

## 🔧 Технические детали

### API Endpoints
- **Jupiter Quote API:** `https://quote-api.jup.ag/v6/quote`
- **Jupiter Swap API:** `https://quote-api.jup.ag/v6/swap`
- **Backend API:** `POST /api/dogWater`

### Токены
- **Input:** SOL (Native) - `So11111111111111111111111111111111111111112`
- **Output:** DogWater - `99smS99MkGP8WFggmUZWaVbe18Y8iWuC3YhGtUMMBray`

### Параметры свапа
```typescript
{
  amount: 1_000_000, // 0.001 SOL (lamports)
  slippageBps: 300,  // 3% slippage
  wrapAndUnwrapSol: true,
  dynamicComputeUnitLimit: true,
  prioritizationFeeLamports: 'auto'
}
```


Автоматически показывается на всех страницах если условие выполнено.

## 🎨 UI/UX

### Дизайн
- Полноэкранное модальное окно с затемненным фоном
- Градиентная кнопка (purple → pink)
- Анимация загрузки при обработке транзакции
- Toast уведомления для всех состояний

### Состояния
- **Idle:** Кнопка "Верифицировать" активна
- **Loading:** Кнопка "Верификация..." с индикатором загрузки
- **Success:** Toast + автоматическая перезагрузка через 1.5 сек
- **Error:** Toast с описанием ошибки

## 🔒 Безопасность

### Проверки
- ✅ Наличие подключенного кошелька
- ✅ Валидация транзакции через Jupiter
- ✅ Подтверждение в сети Solana
- ✅ Обновление флага в БД только после успешной транзакции

### Обработка ошибок
- User rejected transaction
- Network errors
- Jupiter API errors
- Database update errors

## 🚀 Использование

Компонент работает полностью автоматически:
1. Пользователь подключает кошелек
2. Если `isBoughtDogWater === false` → показывается попап
3. Пользователь верифицируется через Jupiter Swap
4. Попап исчезает после успешной верификации

## 📝 Примечания

- Транзакция использует Jupiter Aggregator для лучшей ликвидности
- Курс SOL/USD может меняться, сумма в токенах будет динамической
- После верификации страница перезагружается для обновления состояния пользователя
- В случае отмены транзакции пользователь может попробовать снова
