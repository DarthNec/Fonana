## 🌐 PHASE 2: РЕСУРСЫ ЖЕНСКИХ АВАТАРОВ

### 2.1 БЕСПЛАТНЫЕ API С КОММЕРЧЕСКОЙ ЛИЦЕНЗИЕЙ

#### ⭐ Unsplash API
- **URL:** https://unsplash.com/developers
- **Лимиты:** 50 requests/hour (Demo), 5000/hour (Production)
- **Лицензия:** Unsplash License (бесплатно для коммерческого использования)
- **Качество:** Высокое (профессиональные фото)
- **Поиск:** По keyword `portrait woman`, `female face`, `girl headshot`
- **Формат:** JPG, различные размеры
- **Плюсы:** 
  - ✅ Реальные профессиональные фото
  - ✅ Высокое качество
  - ✅ Бесплатно
  - ✅ Широкий выбор
- **Минусы:**
  - ❌ Rate limits
  - ❌ Требует API key
  - ❌ Нужна атрибуция фотографа

#### ⭐ Pexels API
- **URL:** https://www.pexels.com/api/
- **Лимиты:** 200 requests/hour
- **Лицензия:** Pexels License (коммерческое использование без атрибуции)
- **Качество:** Высокое
- **Поиск:** По keyword `woman portrait`, `female headshot`
- **Плюсы:**
  - ✅ Не требует атрибуции
  - ✅ Высокое качество
  - ✅ Бесплатно
- **Минусы:**
  - ❌ Rate limits ниже чем Unsplash

#### ⭐ Pixabay API
- **URL:** https://pixabay.com/api/docs/
- **Лимиты:** 5000 requests/hour
- **Лицензия:** Pixabay License (коммерческое использование)
- **Качество:** Среднее-высокое
- **Плюсы:**
  - ✅ Высокие лимиты
  - ✅ Бесплатно
- **Минусы:**
  - ❌ Качество может варьироваться

### 2.2 AI-ГЕНЕРАТОРЫ АВАТАРОВ

#### ⭐ DiceBear (текущее решение)
- **URL:** https://dicebear.com
- **Версия:** 9.x
- **Стили:** avataaars, adventurer, big-ears, lorelei, notionists
- **Лицензия:** MIT/CC0 (полностью бесплатно)
- **Качество:** SVG (масштабируется)
- **Плюсы:**
  - ✅ Уже интегрировано
  - ✅ Бесплатно без лимитов
  - ✅ SVG (легковесно)
  - ✅ Консистентный стиль
- **Минусы:**
  - ❌ Мультяшный стиль (не реалистичные фото)
  - ❌ Ограниченная кастомизация женских черт

**Женские стили DiceBear:**
- `lorelei` - стилизованные женские лица
- `avataaars` - поддерживает женские прически/аксессуары
- `big-ears` - гендерно-нейтральные персонажи

#### 🔥 This Person Does Not Exist
- **URL:** https://thispersondoesnotexist.com
- **Технология:** StyleGAN2 (Nvidia)
- **API:** Неофициальные (generated.photos)
- **Лицензия:** Зависит от сервиса
- **Качество:** Фотореалистичное
- **Плюсы:**
  - ✅ 100% синтетические лица (нет GDPR проблем)
  - ✅ Фотореалистично
  - ✅ Уникальные лица
- **Минусы:**
  - ❌ Нет официального бесплатного API
  - ❌ Generated.photos стоит $20-100/мес

#### ⭐ UIFaces / RandomUser.me
- **URL:** https://randomuser.me
- **Лимиты:** 5000 requests/day
- **Лицензия:** MIT
- **Качество:** Реальные фото
- **Плюсы:**
  - ✅ API бесплатен
  - ✅ Можно фильтровать по gender=female
  - ✅ Включает полные профили
- **Минусы:**
  - ❌ Ограниченная база (~100-200 уникальных лиц)

### 2.3 ГОТОВЫЕ ДАТАСЕТЫ

#### Kaggle / GitHub Datasets
- **CelebA Dataset** - 200K+ женских лиц знаменитостей
- **Labeled Faces in the Wild** - 13K+ лиц
- **UTKFace** - 20K+ лиц с метаданными (возраст, пол)

- ⚠️ Требуют скачивания и хранения (GB размеры)
- ⚠️ Сложные лицензии (часто только для research)

### 2.4 ПЛАТНЫЕ СЕРВИСЫ (для полноты картины)

- **Цена:** $20-100/мес
- **База:** 100K+ AI-сгенерированных лиц
- **API:** Полноценный REST API
- **Фильтры:** Возраст, пол, эмоции, этничность

#### Vidnoz / AiGen
- **Цена:** $10-30/мес
- **База:** 500-1500 готовых аватаров
- **Качество:** Высокое (AI-generated)

## 🚦 PHASE 5: RED FLAGS И РИСКИ

### 🔴 CRITICAL RED FLAGS

**1. Юридические риски датасетов:**
- CelebA, LFW, UTKFace = лица реальных людей БЕЗ согласия на коммерческое использование
- ⚠️ **РИСК:** Lawsuit, GDPR штрафы
- ✅ **РЕШЕНИЕ:** Использовать только AI-generated ИЛИ licensed sources

**2. Rate Limits на бесплатных API:**
- Unsplash Demo: 50 requests/hour = слишком мало для массовой загрузки
- ⚠️ **РИСК:** Блокировка при попытке загрузить 100+ аватаров
- ✅ **РЕШЕНИЕ:** Batch download с паузами ИЛИ Production API key

**3. Атрибуция (Unsplash):**
- Требует указывать фотографа
- ⚠️ **РИСК:** Нарушение лицензии если не указать
- ✅ **РЕШЕНИЕ:** Использовать Pexels (не требует) ИЛИ сохранить metadata

### 🟡 MEDIUM RISKS

**4. Качество RandomUser.me:**
- Ограниченная база (~100-200 уникальных лиц)
- ⚠️ **РИСК:** Повторяющиеся аватары
- ✅ **РЕШЕНИЕ:** Использовать как дополнение, не основной источник

**5. DiceBear мультяшность:**
- Не фотореалистичные
- ⚠️ **РИСК:** Может не соответствовать бренду Fonana
- ✅ **РЕШЕНИЕ:** Использовать только как fallback
