## CSS Box Model: Почему 24px → 28px?

### Анатомия Кнопки

```
┌─────────────────────────────────────────────┐
│                                             │
│    Shadow-lg (не влияет на размер)          │
│    ┌─────────────────────────────────────┐  │
│    │                                     │  │
│    │  border-2 border-white (2px)        │  │
│    │  ┌───────────────────────────────┐  │  │
│    │  │                               │  │  │
│    │  │      w-6 h-6 (24px)          │  │  │ ← CONTENT BOX
│    │  │                               │  │  │   Заявленный размер
│    │  │      [Icon: w-3 h-3 (12px)]  │  │  │
│    │  │                               │  │  │
│    │  └───────────────────────────────┘  │  │
│    │        ↑ 24px ↑                     │  │
│    │  ├─2px─┤      ├─2px─┤               │  │
│    └─────────────────────────────────────┘  │
│          ↑ 28px ↑                           │
│    ├─────┤      ├─────┤                     │
└─────────────────────────────────────────────┘

ФОРМУЛА:
Total Width  = content-width + border-left + border-right
             = 24px + 2px + 2px
             = 28px

Total Height = content-height + border-top + border-bottom
             = 24px + 2px + 2px
             = 28px
```

**Вывод:** Border добавляется СНАРУЖИ content box → +4px к размеру!

## Визуальные Факторы Восприятия

### 1. Border Contrast

```
 Dark Background (bg-slate-900: #0f172a)
┌────────────────────────────────────┐
│                                    │
│  ┌──────────────────────────────┐  │
│  │ White Border (2px)           │  │ ← Высокий контраст
│  │ ┌──────────────────────────┐ │  │
│  │ │                          │ │  │
│  │ │  Purple/Pink Gradient    │ │  │ ← Яркий цвет
│  │ │                          │ │  │
│  │ └──────────────────────────┘ │  │
│  └──────────────────────────────┘  │
│                                    │
└────────────────────────────────────┘
```

**Эффект:** Белая граница на темном фоне создаёт "halo" эффект.

---

### 2. Shadow Effect

```
Button with shadow-lg:

        ┌─────────┐
       ╱│         │╲      ← Shadow расширяет
      ╱ │  Button │ ╲       визуальную область
     │  │         │  │
      ╲ │         │ ╱
       ╲│         │╱
        └─────────┘
```

**Эффект:** Shadow не влияет на layout, но визуально кнопка кажется на 10-15% крупнее.

---

### 3. Positioning "Выступ"

```
Avatar boundary:
┌────────────────────┐
│                    │
│                    │
│                    ├──┐
│                    │▓▓│ ← Button "выступает"
└────────────────────┼──┘   на 4px (-bottom-1 -right-1)
                     │▓▓│
                     └──┘
```

**Эффект:** Кнопка визуально "больше" занимаемого пространства.

## Почему Это Важно?

### 1. Визуальный Баланс

┌──────────┐                 ┌──────────┐
│          │                 │          │
│  Avatar  │                 │  Avatar  │

           └──┘                       └─┘

**Проблема:** Кнопка "давит" на avatar, привлекает слишком много внимания.

---

### 2. Touch Target (Мобильный UX)

**Apple HIG (Human Interface Guidelines):**
- Минимальный touch target: 44pt (≈44px)
- Рекомендуемый: 44-48pt

**Android Material Design:**
- Минимальный touch target: 48dp (≈48px)

**Текущий Fonana Mobile:**
- Button: 28px (физический размер)
- Clickable area: ~32px (с positioning)
- **НИЖЕ** рекомендаций! ⚠️

**Решение:**
- Сохранить визуальный размер 24px
- Увеличить clickable area через padding/pseudo-element

---

### 3. Консистентность Mobile ↔ Desktop

```
Mobile (43.75%)  vs  Desktop (36.67%)
     ↓                      ↓
   ┌───┐                  ┌───┐
   │▓▓▓│ Слишком крупно   │▓▓ │ Пропорционально
   └───┘                  └───┘
```

**Проблема:** Пользователи видят РАЗНЫЕ пропорции на разных устройствах.

**Цель:** Одинаковое визуальное восприятие (36-38% от avatar).

## Альтернативное Решение: box-sizing

### Concept: Border внутри Content Box

```
Default (box-sizing: content-box):
┌─────────────────────┐
│ border-2 (2px)      │
│ ┌─────────────────┐ │
│ │                 │ │
│ │  w-6 (24px)     │ │  → Total: 28px
│ │                 │ │
│ └─────────────────┘ │
└─────────────────────┘

With box-border (box-sizing: border-box):
┌─────────────────────┐
│ w-6 (24px TOTAL)    │
│╔═══════════════════╗│
│║ border-2 (2px)    ║│
│║ ┌───────────────┐ ║│
│║ │  Content 20px │ ║│  → Total: 24px ✅
│║ └───────────────┘ ║│
│╚═══════════════════╝│
└─────────────────────┘
```

**Code:**
```typescript
className="w-6 h-6 border-2 box-border"
```

**Плюсы:**
- Точный контроль итогового размера (24px)

**Минусы:**
- Content area = 20px (иконки будут плотнее)
- Border "съедает" пространство для иконки

---

## Итоговая Рекомендация

**Решение:** `w-5 h-5` + `w-2.5 h-2.5` иконки

**Почему:**
1. ✅ Итоговый размер: 24px (как ожидается)
2. ✅ Пропорция: 37.5% (близко к desktop 36.67%)
3. ✅ Иконки: 10px в 20px content (50% fill rate - идеально)
4. ✅ Консистентность между mobile/desktop
5. ✅ Соответствие UI best practices
