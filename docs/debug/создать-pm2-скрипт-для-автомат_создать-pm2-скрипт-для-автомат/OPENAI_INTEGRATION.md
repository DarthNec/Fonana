## 🔧 Технические детали OpenAI

### API Configuration:

```javascript
const openai = new OpenAI({
  apiKey: process.env.NEXT_PUBLIC_OPENAI_API_KEY
})
```

### Request Parameters:

```javascript
const response = await openai.chat.completions.create({
  model: 'gpt-3.5-turbo',        // Модель
  messages: [
    { 
      role: 'user', 
      content: smartPrompt         // SMART промпт с контекстом
    }
  ],
  max_tokens: 80,                  // Длина комментария
  temperature: 0.9                 // Высокая вариативность
})
```

### Response Processing:

```javascript
const comment = response.choices[0].message.content
  .trim()                          // Убираем пробелы
  .replace(/^["']|["']$/g, '')     // Убираем кавычки
  .slice(0, 100)                   // Максимум 100 символов
```

${postCategory ? `Категория: ${postCategory}` : ''}
