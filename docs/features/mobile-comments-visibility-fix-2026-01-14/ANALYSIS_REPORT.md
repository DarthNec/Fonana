## 🎯 Проблема

При открытии панели комментариев на мобильных устройствах кнопка "Отправить" в форме комментария скрывается за нижним навигационным баром (`BottomNav`), что делает невозможным отправку комментария без прокрутки или закрытия панели.

### Визуальная проблема

```
┌─────────────────────────┐
│ Comments Panel Header   │
│─────────────────────────│
│                         │
│ Comment 1               │
│ Comment 2               │
│ ...                     │
│─────────────────────────│
│ Comment Form            │
│ [textarea]              │
│ [Анонимно] [300/300]    │
│ [Отправить] ← СКРЫТА    │ ← Перекрывается BottomNav
└─────────────────────────┘
┌─────────────────────────┐
│   🏠  🔍  ➕  📚  👤    │ ← BottomNav z-50
└─────────────────────────┘
```

## 📊 Z-Index иерархия (текущая)

| Компонент | Desktop | Mobile | Конфликт |
|-----------|---------|--------|----------|
| Overlay (Comments) | z-40 | z-40 | ❌ Под панелью |
| **SlidingCommentsPanel** | z-50 | **z-50** | ⚠️ **Конфликт с BottomNav** |
| **BottomNav** | (скрыт) | **z-50** | ⚠️ **Конфликт с Comments** |
| Profile Overlay | - | z-[60] | ✅ Выше |
| Profile Panel | - | z-[70] | ✅ Выше |
| Emoji Picker (Comment) | z-[9999] | z-[9999] | ✅ Выше всего |

### Проблема

`SlidingCommentsPanel` (z-50) = `BottomNav` (z-50) → **Одинаковый уровень, BottomNav перекрывает форму**

## 📊 Context7 Best Practices

### Tailwind CSS z-index

**Рекомендации из документации:**
- `z-0` до `z-50` - обычный контент
- `z-[51]` до `z-[99]` - модальные окна, панели
- `z-[100+]` - тосты, критичные уведомления

**Наше использование:** ✅ Соответствует (z-[54-55])

### Mobile-First Design

**Pattern:**
```tsx
// Базовый стиль для мобильных
'z-[55]'

// Переопределение для desktop
'md:z-50'
```

**Antipattern:**
```tsx
// ❌ Desktop-first
'z-50 max-md:z-[55]'
```

**Наш случай:** Используем `max-md:` так как desktop версия уже работает корректно
