# SOLUTION PLAN: Решение проблемы зависания терминала при SSH командах

## 🎯 Цель задачи

Решить проблему зависания терминала при выполнении интерактивных SSH команд в Cursor IDE, используя неинтерактивные методы и альтернативные подходы для настройки безарольного SSH доступа.

## 📋 Детальный план реализации

### Этап 1: Диагностика существующих ресурсов (5 минут)

#### 1.1 Проверка существующих SSH ключей
```powershell
# Проверить существующие ключи
Get-ChildItem "C:\Users\blitz\.ssh\id_*" -ErrorAction SilentlyContinue

# Проверить SSH конфигурацию
Test-Path "C:\Users\blitz\.ssh\config"

# Проверить известные хосты
Test-Path "C:\Users\blitz\.ssh\known_hosts"
```

#### 1.2 Проверка SSH функциональности
```powershell
# Проверить версию SSH
ssh -V

# Проверить доступность агента
ssh-add -l
```

### Этап 2: Создание SSH ключей неинтерактивным способом (10 минут)

#### 2.1 Создание ключа с автоматическими параметрами
```powershell
# Создать ED25519 ключ без интерактивного ввода
ssh-keygen -t ed25519 -f "C:\Users\blitz\.ssh\id_ed25519_fonana" -N "" -C "fonana-server-key"

# Альтернативно: создать RSA ключ
ssh-keygen -t rsa -b 4096 -f "C:\Users\blitz\.ssh\id_rsa_fonana" -N "" -C "fonana-server-key"
```

#### 2.2 Проверка создания ключей
```powershell
# Проверить созданные файлы
Get-ChildItem "C:\Users\blitz\.ssh\id_*fonana*"

# Проверить содержимое публичного ключа
Get-Content "C:\Users\blitz\.ssh\id_ed25519_fonana.pub"
```

### Этап 3: Настройка SSH конфигурации (5 минут)

#### 3.1 Обновление SSH конфигурации
```powershell
# Добавить конфигурацию для использования нового ключа
Add-Content "C:\Users\blitz\.ssh\config" @"
Host fonana-server
    HostName 64.20.37.222
    User root
    Port 22
    IdentityFile C:\Users\blitz\.ssh\id_ed25519_fonana
    ServerAliveInterval 60
    ServerAliveCountMax 3
    TCPKeepAlive yes
    Compression yes
"@
```

#### 3.2 Тестирование конфигурации
```powershell
# Проверить синтаксис конфигурации
ssh -F "C:\Users\blitz\.ssh\config" -T fonana-server
```

### Этап 4: Передача публичного ключа на сервер (15 минут)

#### 4.1 Создание скрипта для передачи ключа
```powershell
# Создать PowerShell скрипт для автоматизации
$script = @"
# Получить публичный ключ
`$publicKey = Get-Content "C:\Users\blitz\.ssh\id_ed25519_fonana.pub"

# Создать команду для добавления ключа на сервер
`$command = "echo '`$publicKey' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys && chmod 700 ~/.ssh"

# Выполнить команду через SSH (потребует пароль один раз)
ssh root@64.20.37.222 `$command
"@

# Сохранить скрипт
$script | Out-File "C:\Users\blitz\OneDrive\Desktop\Fonana\setup-ssh-key.ps1"
```

#### 4.2 Альтернативный метод через SCP
```powershell
# Скопировать публичный ключ на сервер
scp "C:\Users\blitz\.ssh\id_ed25519_fonana.pub" root@64.20.37.222:/tmp/

# Добавить ключ в authorized_keys (требует пароль)
ssh root@64.20.37.222 "cat /tmp/id_ed25519_fonana.pub >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys && rm /tmp/id_ed25519_fonana.pub"
```

### Этап 5: Тестирование безарольного доступа (10 минут)

#### 5.1 Тестирование подключения
```powershell
# Тест подключения с ключом
ssh -i "C:\Users\blitz\.ssh\id_ed25519_fonana" root@64.20.37.222 "echo 'SSH key authentication successful'"

# Тест через конфигурацию
ssh fonana-server "echo 'SSH config authentication successful'"
```

#### 5.2 Проверка функциональности
```powershell
# Проверить системную информацию
ssh fonana-server "whoami && hostname && pwd"

# Проверить доступ к файловой системе
ssh fonana-server "ls -la /root"
```

## 🔧 Технические детали

### Неинтерактивные команды SSH:

#### 1. Создание ключей
```powershell
# ED25519 ключ (рекомендуется)
ssh-keygen -t ed25519 -f "C:\Users\blitz\.ssh\id_ed25519_fonana" -N "" -C "fonana-server-key"

# RSA ключ (альтернатива)
ssh-keygen -t rsa -b 4096 -f "C:\Users\blitz\.ssh\id_rsa_fonana" -N "" -C "fonana-server-key"
```

#### 2. SSH конфигурация
```ssh
Host fonana-server
    HostName 64.20.37.222
    User root
    Port 22
    IdentityFile C:\Users\blitz\.ssh\id_ed25519_fonana
    ServerAliveInterval 60
    ServerAliveCountMax 3
    TCPKeepAlive yes
    Compression yes
    ForwardAgent no
    StrictHostKeyChecking yes
```

#### 3. Команды для сервера
```bash
# На сервере: создать директорию SSH
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# Добавить публичный ключ
cat /tmp/id_ed25519_fonana.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

# Удалить временный файл
rm /tmp/id_ed25519_fonana.pub
```
