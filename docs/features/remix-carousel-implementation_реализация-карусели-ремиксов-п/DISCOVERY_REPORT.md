# DISCOVERY REPORT - Карусель ремиксов постов

## 🎯 Цель исследования
Реализация карусели ремиксов постов для улучшения UX - связывание оригинальных постов и их ремиксов в единую карусель с переключением между ними кнопками на карточке внутри feed.

## 🔍 Анализ текущей архитектуры

### Структура данных постов
- **Модель Post**: Содержит поле `remixId` для связи с оригинальным постом
- **Связь ремиксов**: Один пост может иметь множество ремиксов через `remixId`
- **Типы постов**: Поддерживаются `ai-video`, `video`, `image`, `audio`, `text`

### Текущая система отображения
- **PostCard**: Основной компонент карточки поста
- **PostContent**: Отображение контента поста (медиа, текст)
- **FeedPageClient**: Главная страница ленты с постами
- **PostsContainer**: Контейнер для отображения списка постов
- **PostList**: Компонент списка постов

### Существующие карусели/слайдеры
- **PostGallery**: Галерея медиа постов с модальным просмотром
- **MediaViewerModal**: Модальное окно для просмотра медиа с навигацией
- **OptimizedImage**: Компонент оптимизированного изображения

## 📊 Анализ требований

### Функциональные требования
1. **Группировка постов**: Оригинальный пост + все его ремиксы в одну группу
2. **Навигация**: Кнопки для переключения между постами в группе
3. **Визуальная связь**: Индикация того, что посты связаны
4. **Производительность**: Минимальное влияние на скорость загрузки ленты

### Нефункциональные требования
1. **UX**: Интуитивно понятная навигация
2. **Производительность**: Быстрое переключение между постами
3. **Адаптивность**: Работа на мобильных и десктопных устройствах
4. **Совместимость**: Интеграция с существующей системой постов

## 🎨 Варианты реализации

### Вариант 1: Встроенная карусель в PostCard
**Описание**: Добавить карусель непосредственно в PostCard с кнопками навигации
**Преимущества**:
- Минимальные изменения в архитектуре
- Быстрая реализация
- Сохранение существующего UX

**Недостатки**:
- Усложнение PostCard
- Ограниченная гибкость

### Вариант 2: Отдельный компонент RemixCarousel
**Описание**: Создать отдельный компонент для отображения группы ремиксов
**Преимущества**:
- Чистая архитектура
- Переиспользуемость
- Легкое тестирование

**Недостатки**:
- Больше изменений в коде
- Необходимость рефакторинга существующих компонентов

### Вариант 3: Модальное окно с каруселью
**Описание**: При клике на пост открывается модальное окно с каруселью ремиксов
**Преимущества**:
- Полноэкранный просмотр
- Богатые возможности навигации
- Не влияет на основной feed

**Недостатки**:
- Дополнительный клик для доступа
- Может нарушить flow пользователя

## 🔧 Технические соображения

### API изменения
- **Новый endpoint**: `/api/posts/remix-group/{postId}` для получения группы ремиксов
- **Модификация существующих**: Добавить информацию о ремиксах в ответы API

### Состояние компонентов
- **Локальное состояние**: Текущий индекс в карусели
- **Глобальное состояние**: Кэширование групп ремиксов

### Производительность
- **Ленивая загрузка**: Загружать ремиксы только при необходимости
- **Кэширование**: Сохранять группы ремиксов в памяти
- **Оптимизация**: Минимизировать количество API запросов

## 📱 Мобильные соображения

### Навигация
- **Свайпы**: Поддержка жестов для переключения
- **Кнопки**: Четкие кнопки навигации
- **Индикаторы**: Визуальные индикаторы текущего поста

### Производительность
- **Виртуализация**: Загружать только видимые посты
- **Оптимизация изображений**: Адаптивные размеры для мобильных
