# ARCHITECTURE CONTEXT - Карусель ремиксов постов

## 🏗️ Текущая архитектура системы постов

### Компонентная структура
```
FeedPageClient
├── PostsContainer
│   ├── PostList
│   │   └── PostCard (для каждого поста)
│   │       ├── PostHeader
│   │       ├── PostContent
│   │       │   ├── Media (image/video/audio)
│   │       │   ├── Text content
│   │       │   └── Remix button (для видео с requestId)
│   │       ├── PostActions
│   │       └── CommentsSection
│   └── PostGrid (альтернативный layout)
```

### Модель данных
```typescript
interface UnifiedPost {
  id: string
  creator: PostCreator
  content: PostContent
  media: PostMedia
  access: PostAccess
  engagement: PostEngagement
  commerce: PostCommerce
  createdAt: Date
  updatedAt: Date
  // Новое поле для ремиксов
  remixId?: string
}
```

### Существующие карусели
1. **PostGallery**: Галерея медиа с модальным просмотром
2. **MediaViewerModal**: Полноэкранный просмотр медиа с навигацией
3. **OptimizedImage**: Оптимизированное отображение изображений

## 🔗 Связи между постами и ремиксами

### Текущая структура
- **Оригинальный пост**: `remixId = null`
- **Ремикс поста**: `remixId = ID оригинального поста`
- **Связь**: Один ко многим (один оригинал → много ремиксов)

### Примеры связей
```
Post A (оригинал) → Post B (ремикс A) → Post C (ремикс A)
Post D (оригинал) → Post E (ремикс D)
Post F (оригинал) → Post G (ремикс F) → Post H (ремикс F)
```

## 📊 Анализ существующих компонентов

### PostCard
**Текущая функциональность**:
- Отображение одного поста
- Поддержка различных вариантов (full, compact, minimal)
- Обработка действий (лайки, комментарии, ремиксы)
- Адаптивный дизайн

**Возможности для расширения**:
- Добавление состояния карусели
- Интеграция с RemixCarousel
- Обработка навигации между постами

### PostContent
**Текущая функциональность**:
- Отображение медиа контента
- Поддержка различных типов медиа
- Кнопка Remix для видео с requestId
- Адаптивные размеры

**Возможности для расширения**:
- Интеграция с каруселью медиа
- Поддержка навигации между постами
- Индикаторы текущего поста

### FeedPageClient
**Текущая функциональность**:
- Управление состоянием ленты
- Фильтрация и сортировка постов
- Бесконечная прокрутка
- Real-time обновления

**Возможности для расширения**:
- Группировка постов по ремиксам
- Кэширование групп ремиксов
- Оптимизация загрузки

## 🎯 Точки интеграции

### 1. API Layer
**Текущие endpoints**:
- `GET /api/posts` - получение постов
- `POST /api/posts/remix` - создание ремикса
- `GET /api/posts/{id}` - получение конкретного поста

**Новые endpoints**:
- `GET /api/posts/remix-group/{postId}` - получение группы ремиксов
- `GET /api/posts/{id}/remixes` - получение ремиксов конкретного поста

### 2. State Management
**Текущее состояние**:
- Локальное состояние в компонентах
- Zustand store для пользователя
- LocalStorage для лайков

**Новое состояние**:
- Кэш групп ремиксов
- Текущий индекс в карусели
- Состояние загрузки ремиксов

### 3. Component Integration
**Точки интеграции**:
- PostCard → RemixCarousel
- PostContent → MediaCarousel
- FeedPageClient → RemixGroupManager

## 🔄 Потоки данных

### Текущий поток
```
API → PostsContainer → PostList → PostCard → PostContent
```

### Предлагаемый поток
```
API → PostsContainer → PostList → PostCard → RemixCarousel → PostContent
                    ↓
              RemixGroupManager (кэширование групп)
```

### Текущие ограничения

### Новые ограничения

## 📋 Архитектурные решения

### 1. Группировка постов
**Решение**: Создать RemixGroupManager для управления группами
**Обоснование**: Централизованное управление состоянием групп

### 2. Навигация
**Решение**: Использовать существующие паттерны навигации
**Обоснование**: Консистентность с текущим UX

### 3. Кэширование
**Решение**: Локальное кэширование групп в памяти
**Обоснование**: Быстрый доступ к данным без API запросов

### 4. Адаптивность
**Решение**: Responsive design с мобильными жестами
**Обоснование**: Поддержка всех устройств
