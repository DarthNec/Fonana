## ✅ Выполненные изменения

### 1. Обновление позиционирования emoji picker в `desktopIndex.tsx`

**Файл**: `components/posts/core/CommentsSection/desktopIndex.tsx`

#### Изменение: Адаптивное позиционирование picker
```diff
{showEmojiPicker && (
  <div 
    ref={emojiPickerRef}
-   className="absolute right-0 top-full mt-2 z-[9999]"
+   className={cn(
+     "absolute right-0 z-[9999]",
+     // На мобильном - вверх, на desktop - вниз
+     "max-md:bottom-full max-md:mb-2",
+     "md:top-full md:mt-2"
+   )}
  >
    <EmojiPicker
      onEmojiClick={handleEmojiClick}
      width={350}
      height={400}
    />
  </div>
)}
```

**Объяснение**: 
- Добавлен `cn()` для условного применения классов
- `max-md:bottom-full max-md:mb-2` - открывает picker **вверх** на мобильных устройствах (< 768px)
- `md:top-full md:mt-2` - открывает picker **вниз** на desktop (≥ 768px)
- `z-[9999]` сохранён для отображения поверх всех элементов
