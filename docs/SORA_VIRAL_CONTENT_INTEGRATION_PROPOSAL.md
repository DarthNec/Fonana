**Вопрос:** Хранить шаблоны в коде или в БД?

**Мое мнение:** 
- Начать с кода (проще, быстрее)

### 2. Персонализация

**Мое мнение:**
- Сначала готовые шаблоны

- Для MVP не критично
- Но полезно для долгосрочной стратегии

**Мое мнение:**
- Все новые поля опциональные (nullable)
- Новые API endpoints расширяют существующие
- Обратная совместимость сохранена

## 📊 Структура файла шаблонов (предложение)

```typescript
// lib/sora-templates.ts

export type SoraCategory = 
  | 'false-reality' 
  | 'cinematic-mundane' 
  | 'cognitive-glitch'

export type Template = {
  id: string
  name: string
  description: string
  prompt: string
  category: SoraCategory
  subcategory: string
  duration: number  // секунды
  size: string      // "1080x1920"
  tags: string[]
  viralPotential: 'high' | 'medium' | 'low'  // на основе исследования
}

export const soraTemplates: Record<SoraCategory, Template[]> = {
  'false-reality': [
    {
      id: 'reverse-time-egg',
      name: 'Обратное время (яйцо)',
      description: 'Женщина разбивает яйцо, осколки собираются обратно',
      prompt: 'Крупный план молодой женщины 30 лет в обычной московской квартире-хрущевке. Она разбивает яйцо на сковороду, осколки собираются обратно в целое яйцо. Утренний свет через окно. Женщина медленно поднимает голову и смотрит, не понимая что происходит. Стиль: документальная съемка, скрытая камера, естественное освещение, реалистичные текстуры, мелкие детали интерьера. 4K, 24fps, кинематографичное качество.',
      category: 'false-reality',
      subcategory: 'impossible-daily',
      duration: 15,
      size: '1080x1920',
      tags: ['кухня', 'невозможное', 'время'],
      viralPotential: 'high'
    },
    // ... еще шаблоны
  ],
  // ... другие категории
}

// Helper функции
export function getTemplatesByCategory(category: SoraCategory): Template[] {
  return soraTemplates[category] || []
}

export function getTemplateById(id: string): Template | undefined {
  return Object.values(soraTemplates)
    .flat()
    .find(t => t.id === id)
}

export function getHighViralTemplates(): Template[] {
  return Object.values(soraTemplates)
    .flat()
    .filter(t => t.viralPotential === 'high')
}
```
