**Для быстрого применения перед каждой рекомендацией**

---

## 🚨 Red Flags - СТОП сигналы

### 1. "Быстрое решение"
```
🚨 Разница < 30 минут → Выбирай ПРАВИЛЬНОЕ, не быстрое!
```

### 2. "Данные доступны, но не используются"
```
🚨 const user = useUser() ← есть в scope
   someMethod(data) ← user НЕ передаётся
   → ПОЧЕМУ? Может это решение?
```

### 3. "Минимальные изменения"
```
🚨 Workaround → НЕ основное решение!
```

### 4. "Логика в разных местах"
```
🚨 3+ места с одной логикой → Нарушение DRY!
```

---

## ✅ Обязательный чеклист (7 пунктов)

```
1. ❓ Проанализировал ВСЕ доступные данные в scope?
2. ❓ Изучил существующие паттерны?
3. ❓ Создал матрицу решений (3+ варианта)?
4. ❓ Рассчитал SCORE для каждого?
5. ❓ Проверил Red Flags?
6. ❓ Задал "Почему?" 5 раз?
7. ❓ Рекомендую решение с MAX SCORE?
```

**Хотя бы один "НЕТ" → СТОП! Переделай!**

---

## 📊 Scoring Formula

```
SCORE = Architecture(30%) + Security(25%) + Speed(15%) + Risk(15%) + Maintainability(15%)
```

**Рекомендовать:** Решение с **МАКСИМАЛЬНЫМ SCORE**

---

## 🎯 Ключевые принципы

1. **Правильное > Быстрое**
2. **Root Cause > Симптом**
3. **Используй доступное**
4. **Задавай вопросы**
5. **ВСЕГДА матрица решений**
