# 🚀 Fonana Changelog

## 📅 26 февраля 2026

### 🌐 Fonana Web
- 🧹 **Рефакторинг кодовой базы** - Провёл масштабный рефакторинг, убрал множество неиспользуемых компонентов и dead кода, оптимизировал структуру проекта
- 👻 **Phantom Wallet (браузерная версия)** - Пофиксил подключение кошелька из браузера Phantom, теперь внутри Phantom он сразу детектит кошелёк и не предлагает его повторно установить. Зафиксил детект кошелька: если браузерная версия не может найти кошелёк, предлагает установить его с переносом пользователя на страницу Phantom
- 💬 **Высота блока комментариев** - Пофиксил закрытие блока комментариев, теперь он имеет высоту `75vh` от высоты экрана, header и кнопка закрытия видны всегда на любых устройствах
- 💰 **Ограничение платных действий (Messages)** - Ограничил кнопки платного сообщения и чаевых на странице сообщений, теперь просит подключить кошелёк прежде чем отправлять чаевые
- 📱 **Фикс скролла постов (Mobile Comments)** - Пофиксил перелистывание постов при скролле в блоке комментариев на мобильном виде
- ⚡ **Оптимизация лотереи (UX)** - Убрал иконку загрузки и полупрозрачный фон при прокручивании колеса
- 🔐 **Защита от абуза лотереи** - Исключил возможность абузить систему лотереи, всё происходит на backend, frontend отрисовывает только результат
- 🎰 **Система призов лотереи** - Лотерея полностью работает: посты начисляются и добавляются сразу на страницу Purchases, у пользователя перманентный доступ, дополнительные генерации начисляются мгновенно
- 🔊 **Звуки лотереи** - Добавил звуки при взаимодействии с лотереей (вращение, выигрыш, проигрыш)
- 🎲 **Lottery в мобильном меню** - Добавил переход в лотерею с мобильного вида по кнопке из бокового меню
- 🔄 **Ежедневные вращения** - Создал автоматическую систему начисления вращений: каждый день в 00:00 всем пользователям с 0 вращений начисляется 1 бесплатное вращение
