# 🚀 Fonana Changelog

## 📅 6 ноября 2025

### 🌐 Fonana Web
- ✅ **Скейлинг историй** - пофиксил скейлинг историй, горизонтальные изображения больше не открываются во весь экран, а имеют размер обычных историй
- ✅ **Размеры backgroundImage** - пофиксил размеры backgroundImage в профилях пользователей
- ➕ **Активность по колокольчику** - при нажатии на колокольчик подгружаю активность (лайки, эмоции, коменты)
- ✅ **Упрощение платных постов** - убрал задвоение логики платных постов, теперь только 1 способ создания платного поста через Paid параметр в модалке
- ✅ **Ремиксы постов** - пофиксил ремиксы постов, логика переключения теперь снизу поверх контента
- ✅ **Размеры контейнеров** - пофиксил забагованные размеры контейнеров

### 📱 Fonana Mobile
- ✅ **Платные посты владельцев** - пофиксил платные посты, теперь у владельцев платных постов не показывается замок на их постах
- ✅ **Отображение Генераций** - исправлено отображение создающихся постов, в профилях только владельцы теперь их могут видеть
- ✅ **Ошибки создания постов** - зафикшены внутренние ошибки и иные internal errors при создании постов
- ✅ **Лента постов профиля** - добавлено отображение всех постов пользователя в профиле, при скроле вниз подгружает следующие посты
- ➕ **Чекалка версий** - сделал чекалку версий, апка сразу будет предупреждать о новой версии и предложит пользователю обновиться

## 🔧 Предыдущие обновления

### 🌐 Fonana (Web)
- ✅ **Размер горизонтальных постов** - пофиксил размер горизонтальных постов, контейнер больше не вытягивается насильно
- ✅ **Ошибка с Phantom** - пофиксил ошибку с фантомом, если он не установлен в браузере - он больше не будет показывать "Phantom detected", а будет перебрасывать пользователя на страницу установки аддона
- ✅ **Блок комментариев в TikTokViewer** - в TikTokViewer пофиксил блок комментариев, теперь он функционален
- ✅ **Создание ремикса из карусели** - пофиксил создание ремикса, теперь его можно создать из карусели
- ✅ **Показ историй пользователя** - пофиксил ошибку показа всех историй разом, теперь при открытии истории показываются только истории того пользователя, который был выбран
- ➕ **Сторисы** - добавил сторисы, теперь на странице с лентой можно создавать истории, они действительны 24 часа
- ➕ **Скачивание ролика в TikTokViewer** - добавил функции скачивания ролика в TikTokViewer
- ➕ **Генерация никнеймов** - рандомно генерирую никнейм пользователю, как делает фантом, сгенерил исходник из более чем 10к юзернеймов и используем смеси из разных ников для получения уникального
- ➕ **Available generations в Remix** - добавил отображение available generations в remix video
- ➕ **Оптимизация промпта через GPT** - сделал оптимизацию промпта через GPT, теперь промпт проверяется на чернуху, расовую возню и насилие, если промпт могут завернуть, он переделывает его так, чтобы его не завернули и возвращает тебе, ты либо с этим соглашаешься, либо вводишь заново
- ➕ **Редизайн постов** - сделал редизайн постов

### 📱 Fonana Mobile
- ➕ **TikTokView** - добавил TikTokView, вертикальный скролинг, как в рилсах, перемешивает их постоянно, при каждом заходе первым показывается рандомный ролик
- ➕ **Функционал TikTokView** - там же коменты, ремикс, лайки, всё как в вебе
- ➕ **Истории на главную** - добавил истории на главную
- ➕ **Редизайн постов** - сделал редизайн постов
