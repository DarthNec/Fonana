# 🚀 Fonana Changelog

## 📅 27 января 2026

### 🌐 Fonana Web
- ✅ **Редирект фикс** - Пофиксил баг прогрузки сайта из-за редиректа с `/` на `/feed`, добавил оповещение о редиректе, `ERR_FAILED` больше не появляется
- ✅ **Авто-скролл чата** - При открытии чата пофиксил скролл вниз, чат отображается не сверху, а сразу с последнего сообщения, после скрола пользователя позиция чата остаётся неизменной

### 📱 Fonana Mobile
- ✅ **Onboarding экраны** - Изменил onBoardingScreens при входе в приложение, привёл их по цветам к нашим, убрал информацию, более неактуальную
- ✅ **Скачивание роликов** - Пофиксил скачивание роликов через приложение, теперь Bunny напрямую отдаёт файл, минуя апку: web → download → gallery
- ✅ **Уведомление об обновлении** - Пофиксил уведомление об обновлении апки, оно больше не берёт из кэша Prisma, а получает актуальную версию сразу
- ➕ **Tip модалка** - Добавил Tip модалку, теперь с главной под постами можно отправлять типсы криэйторам

## 📅 14 января 2026

### 🌐 Fonana Web
- ✅ **Шеринг постов** - пофиксил шеринг постов, больше нет страницы 404, пост открывается в весь экран
- ✅ **Content Access** - пофиксил отступы от доступности поста на мобильном виде, content access теперь без проблем ставится
- ✅ **Метрики** - добавил метрику по новым пользователям
- ✅ **Комментарии на мобильном** - пофиксил блок комментариев на мобильном виде, теперь кнопка отправить видна и прожимается
- ✅ **Emoji Picker** - пофиксил image picker в блоке комментариев на мобильном виде

### 📱 Fonana Mobile
- ✅ **Отображение ников** - пофиксил отображение ников пользователя в главной ленте и боковых панелях, больше нет случайного набора букв и цифр
- ✅ **Отключение кошелька** - пофиксил отключение кошелька из боковой панели, дата подчищается, контент скрывается
- ✅ **Генерация видео** - пофиксил краш приложения после генерации видео
- ✅ **Страница активностей** - пофиксил страницу активностей для старых пользователей, больше не бьются null поля
- ✅ **Bookmarks** - оптимизировал bookmarks, сразу получаем при входе, моментальная прогрузка
- ✅ **Посты в закладках** - пофиксил отображение постов в закладках, платные посты скрывают контент и пользователи больше не могут просматривать скрытый контент абьюзя через закладки
- ➕ **Анонимные комментарии** - добавил возможность оставлять анонимные комментарии под постами
- ✅ **Ремикс платных постов** - скрыл возможность ремиксить платные и подписочные посты, во избежание засвечивания платного контента
