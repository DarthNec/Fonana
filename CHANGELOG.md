# 🚀 Fonana Changelog

## 🔧 Исправлено
- ✅ **Рендеринг компонентов** - пофиксил повторный рендеринг компонентов без необходимости, при подключении кошелька и отключении главная страница теперь сразу обновляется, скрывая и показывая купленные посты/лайки/комментарии пользователя без необходимости обновлять страницу
- ✅ **Лайки без кошелька** - пофиксил баг с установкой лайка на посты без подключенного кошелька
- ✅ **Лайки в профиле** - пофиксил отображение лайков постов на странице профилей пользователей
- ✅ **Загрузка медиа** - пофиксил загрузку изображений в сообщения, теперь вся медиа льётся на bunny помойку, вместо локалки
- ✅ **Удаление чатов** - исправил удаление чатов пользователей, при нажатии открывается попап снизу, с большой кнопкой "удалить", теперь работает корректно
- ✅ **Платные посты** - пофиксил баг с откупом платных постов и подписки на пользователя, после подтверждения в блокчейне пост теперь сразу открывается
- ✅ **Мобильная навигация** - пофиксил отображение мобильной навигации на странице регистрации реферала (подключение кошелька)
- ✅ **Рефералы в дашборде** - пофиксил отображение количества рефералов в дашборде пользователя
- ✅ **Посты в профиле** - пофиксил отображение постов в профилях пользователей, теперь пост виден без обрезов с боков
- ✅ **Кнопка поделиться** - пофиксил баг с кнопкой "поделиться" в профиле, теперь это единая кнопка для постов и профиля, ошибок нет
- ✅ **AI генерация** - исправил AI Portrait Training, теперь можно генерировать фотки (пока тестово, api ключ временный, там кредитов мало)

## ➕ Добавлено
- ➕ **Индикация загрузки комментариев** - добавлена индикация загрузки комментариев под постами
- ➕ **Кнопка развернуть** - для постов с длинным описанием добавил кнопку "развернуть", которая разворачивает остатки текста
- ➕ **Непрочитанные сообщения** - добавил индикацию непрочитанных сообщений в мобильный бар навигации
